# Nalagreen · Web de la floristería (Palafolls)

Web estática (HTML, CSS y JavaScript sin frameworks).

- `index.html` — página principal
- `css/styles.css` — diseño
- `js/i18n.js` — traducciones al catalán
- `js/main.js` — funciones (menú, idioma, fechas especiales, mapa…)
- `img/` — fotos (pendientes)
- `legal/` — textos legales (pendientes)

Publicada con GitHub Pages desde la rama `main`.
